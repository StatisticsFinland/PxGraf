# Feature map

Use this map when a request names a user-facing workflow or UI element but not a code symbol. Search the **Names people use** column first, then open the linked owner; follow its API or state links only when the request crosses that boundary. Paths are relative to this document. For project structure and endpoint details, see [architecture](architecture.md) and [API documentation](API_DOCUMENTATION.md).

## Save, share, and retrieve

| Names people use | Purpose / where to start | Related code |
|---|---|---|
| Save query, draft, publish-ready, publish, static query, archive | Save the editor state as a query ID. A static/archived query serves a saved data snapshot, while a dynamic query serves current data; reopening either in the editor fetches current table metadata and data. Saving, archiving, or re-archiving a non-draft query triggers the configured publication webhook when enabled; archiving controls the saved data snapshot and is distinct from publication notification. Start at [EditorFooterSection](../PxGraf.Frontend/src/views/Editor/EditorFooterSection.tsx), [SaveDialog](../PxGraf.Frontend/src/components/SaveDialog/SaveDialog.tsx), and [EditorDialogs](../PxGraf.Frontend/src/views/Editor/EditorDialogs.tsx). | [save context](../PxGraf.Frontend/src/contexts/saveContext.tsx), [queries service](../PxGraf.Frontend/src/api/services/queries.ts), [SqController](../PxGraf/Controllers/SqController.cs), [VisualizationController](../PxGraf/Controllers/VisualizationController.cs), [PublicationWebhookService](../PxGraf/Services/PublicationWebhookService.cs) |
| Saved query, query ID, load existing query | Find or reopen a saved configuration; `/sqid/*` fetches it and redirects to the editor. Start at [SavedQueryFinder](../PxGraf.Frontend/src/components/SavedQueryFinder/SavedQueryFinder.tsx) or [QueryLoader](../PxGraf.Frontend/src/views/QueryLoader/QueryLoader.tsx). | [queries service](../PxGraf.Frontend/src/api/services/queries.ts), [SqController](../PxGraf/Controllers/SqController.cs). For saved-query metadata requested separately, see [QueryMetaController](../PxGraf/Controllers/QueryMetaController.cs). |
| Opening broken queries, partial recovery, changed table metadata | When source metadata no longer matches a saved query, loading attempts to recover compatible selections and warns if changes were needed. Start at the load logic in [SqController](../PxGraf/Controllers/SqController.cs), then [QueryLoader](../PxGraf.Frontend/src/views/QueryLoader/QueryLoader.tsx) and the recovery warning in [Editor](../PxGraf.Frontend/src/views/Editor/Editor.tsx). | [queries service](../PxGraf.Frontend/src/api/services/queries.ts), [SqController tests](../UnitTests/ControllerTests/) |
| Shared visualization, visualization API, JSON-stat export | Return a saved query's rendered data or metadata to consumers. Start at [VisualizationController](../PxGraf/Controllers/VisualizationController.cs); preview endpoints are in [CreationController](../PxGraf/Controllers/CreationController.cs). | [JsonStat2DatasetBuilder](../PxGraf/Visualization/JsonStat2DatasetBuilder.cs), [visualization response](VISUALIZATION_RESPONSE.md), [API documentation](API_DOCUMENTATION.md) |
